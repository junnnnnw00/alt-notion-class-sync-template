# Notion 메인 페이지용 사용법

아래 내용을 학기 대시보드의 `사용법` 섹션으로 붙여 넣을 수 있습니다.

## 사용법

수업이 시작되면 Alt에서 녹음을 시작하고, 끝나면 녹음을 종료한다. Alt 요약 생성은 선택 사항이다. 녹취가 준비되면 해당 시간의 수업 페이지 `AI 수업 노트` 아래 `원본 자료`에 자동으로 들어간다.

Codex 정리는 예약된 시간에 새 Alt revision과 `수업 자료` PDF 변경을 확인한다. 새 내용이 있으면 수업별 정리와 과목별 통합 요약을 함께 갱신하고, 바뀐 내용이 없으면 아무것도 수정하지 않는다.

- 자동 기록을 원하지 않는 회차는 그 수업의 `AI 자동 노트` 체크를 끈다. 기존 기록은 남는다.
- 바로 정리하고 싶으면 Codex 작업에서 `$alt-notion-note-curator를 지금 실행해줘`라고 요청한다.
- Alt 데스크톱 0.10.1에서 PDF 없이 녹음한 일반 `노트`에는 나중에 PDF를 붙이거나 `슬라이드` 노트로 바꾸는 메뉴가 없다. 이후 버전에서는 동작이 달라질 수 있다. 기존 녹음은 그대로 두고 같은 수업의 Notion 페이지 `수업 자료`에 PDF를 한 번 넣는다. 파일이 추가·교체·삭제되면 Codex가 녹취와 함께 다시 정리한다.
- `수업 자료`에 넣은 각 PDF는 모든 페이지가 이미지로 변환된다. 이미지는 노트 끝에 따로 모이지 않고, 해당 내용을 설명하는 문단 바로 아래에 `파일명 · 슬라이드 N` 캡션으로 들어간다. 위에서 아래로 읽으면 설명과 슬라이드가 한 흐름으로 이어진다. 파일이 바뀌면 자동 생성한 인라인 이미지만 새로 만들고, 직접 넣은 이미지와 본문은 그대로 둔다. 변환이나 업로드가 실패하면 기존 노트와 이미지를 유지한다.
- 녹음을 빠뜨렸더라도 `수업 자료`에 PDF가 있으면 PDF만으로 노트를 만든다. 이때 교수의 실제 발언이나 슬라이드 밖의 공지는 추정하지 않는다. 나중에 Alt 원본이 생기면 같은 노트를 녹취와 PDF를 합친 버전으로 자동 갱신한다.
- 본문에 PDF 블록만 넣으면 이미 처리 대상으로 잡힌 수업에서는 함께 읽지만, 오래된 수업의 새 자료를 학기 전체에서 확실히 감지하려면 반드시 `수업 자료` 속성에도 넣는다.
- Alt에서도 슬라이드를 따로 보고 싶다면 `노트 추가`에서 종류를 `슬라이드`로 골라 별도 노트를 만든다. 이는 Alt 데스크톱 0.10.1에서 확인한 동작이며 기존 녹음 노트와 합쳐지지 않는다. 해당 버전에서는 PPT/PPTX를 먼저 PDF로 내보낸다.
- 읽을 때는 핵심 요약을 먼저 보고, 이어지는 강의 흐름에서 설명과 관련 슬라이드를 함께 본다.
- Alt 원문과 전체 녹취는 `원본 자료` 안에서 확인한다. Alt 노트가 삭제되거나 연동 범위를 벗어나면 원문은 즉시 제거되고 `Alt · 삭제됨 · revision N`만 남는다. 다음 Codex 정리 때 수업별·과목별 요약도 남은 원문만으로 다시 만든다.
- 시험기간에는 과목별 `통합 요약`에서 핵심 개념, 시험 대비 포인트, 회차별 흐름을 확인한다.
- 동기화가 늦으면 15분 안에 한 번 더 확인하고, 계속 비어 있으면 Worker의 `/health`에서 오류 여부를 본다.

일정 상태나 완료 여부를 따로 관리할 필요는 없다. 수업 시간, 과목, 담당 교수, 장소는 일정 속성에서 확인하고, `수업 자료`는 필요할 때 PDF만 넣는다. 본문은 `핵심 요약` 다음에 `강의 흐름`이 이어지며, 개념 설명 바로 아래에서 관련 슬라이드를 함께 본다.
