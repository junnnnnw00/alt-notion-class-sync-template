# Notion 메인 페이지용 사용법

아래 내용을 학기 대시보드의 `사용법` 섹션으로 붙여 넣을 수 있습니다.

## 사용법

각 수업 일정 페이지는 내 `직접 필기` 공간이다. 수업 중에는 이 페이지에 형식 제한 없이 자유롭게 적는다. 자동화는 직접 필기를 수정·이동·서식 변경·요약하지 않으며, 사실 근거로도 사용하지 않는다. 특정 문장을 교재에 반영하고 싶을 때만 Codex에 그 부분을 지정해서 요청한다.

AI가 만든 내용은 수업 페이지 본문과 섞이지 않고 자식 페이지 `AI 학습 교재`에 들어간다. 수업 페이지에는 이 자식 페이지 링크와 `원본 동기화` 아래 접힌 `원본 자료`만 함께 보인다. `원본 자료`는 Worker가 관리하고, Codex는 읽기만 한다. 따라서 직접 필기, 원본, AI 교재의 소유 영역이 서로 겹치지 않는다.

수업이 시작되면 Alt에서 녹음을 시작하고 끝나면 종료한다. Alt 요약 생성은 선택 사항이다. 녹취가 준비되면 해당 수업 페이지의 `원본 동기화` 아래 `원본 자료`로 들어간다. Codex는 예약된 시간에 새 Alt revision과 `수업 자료` PDF 변경을 확인한 뒤 `AI 학습 교재`와 과목 페이지의 자식 `AI 과목 교재`를 함께 갱신한다. 새 원본이 없으면 아무것도 수정하지 않는다.

`AI 학습 교재`는 짧은 요약이 아니라 한 회차를 독립적으로 공부할 수 있는 문제집형 교재다. 먼저 이번 회차에서 할 수 있어야 할 일을 제시하고, 이어지는 세 개에서 일곱 개의 큰 장에서 정의, 필요한 이유, 작동 원리, 예제나 상태 추적, 흔한 혼동과 다음 개념의 연결을 한 흐름으로 설명한다. 작은 제목과 한 줄 글머리표로 내용을 잘게 쪼개지 않는다.

본문 뒤에는 한 장 복습, 생성 연습문제, 접힌 `정답·해설`이 이어진다. 정답은 문제 바로 아래에 노출되지 않으며, 결론뿐 아니라 풀이 과정, 필수 채점 포인트와 흔한 오답까지 설명한다. 생성 문제는 실제 시험문제나 출제 예상이 아니다. 수업에서 시험, 과제, 마감이나 교수의 강조가 실제로 언급된 경우에만 이를 별도로 정리한다.

본문에는 `[Alt revision …]`이나 `[파일.pdf, p. …]` 같은 출처 문구가 문장마다 반복되지 않는다. 아래쪽의 접힌 `근거 지도`를 열면 각 큰 장, 예제, 공식, 정확한 수치와 공지가 어느 녹취 구간과 PDF 페이지에서 왔는지 확인할 수 있다. 원본 간 충돌이나 확실하지 않은 내용은 숨기지 않고 `확인 필요`에 남긴다.

과목 메인 페이지도 같은 방식으로 분리된다. 자식 `내 과목 정리`는 내가 직접 쓰는 보호 공간이고, 자식 `AI 과목 교재`만 자동으로 갱신된다. `수업별 회차` 아래의 연결된 일정 보기는 그대로 유지된다. 시험기간에는 `AI 과목 교재`의 개념 지도, 통합 설명, 대표 예제와 누적 문제은행을 먼저 보고, 약한 부분만 연결된 회차의 `AI 학습 교재`로 내려가 복습한다.

- 자동 기록을 원하지 않는 회차는 그 수업의 `AI 자동 노트` 체크를 끈다. 기존 직접 필기와 생성된 자식 교재는 남는다.
- 바로 새로 만들고 싶으면 Codex 작업에서 `$alt-notion-note-curator를 지금 실행해줘`라고 요청한다.
- 녹음을 빠뜨렸더라도 같은 수업의 `수업 자료`에 PDF가 있으면 PDF만으로 교재를 만든다. 이 경우 교수의 실제 발언이나 슬라이드 밖의 공지는 추정하지 않는다. 나중에 Alt 원본이 생기면 같은 자식 교재를 녹취와 PDF의 통합본으로 다시 만든다.
- 오래된 수업에 PDF를 나중에 추가할 때는 반드시 `수업 자료` 속성에 넣는다. 페이지 본문에 PDF 블록만 넣으면 학기 전체 변경 탐색에서 놓칠 수 있다.
- 모든 PDF 페이지를 읽지만 이미지 자체가 이해에 필요한 도식, 표, 일정, 수식 배치, 주석 코드와 알고리즘 추적만 `AI 학습 교재` 안의 관련 설명 사이에 넣는다. 표지, 장식, 구획 제목과 일반 글머리표 슬라이드는 반복해서 붙이지 않는다.
- Alt 데스크톱 0.11.1에서 확인한 바로는 PDF 없이 만든 일반 `노트`에 나중에 PDF를 붙이거나 `슬라이드` 노트로 바꾸는 메뉴가 없다. 기존 녹음은 그대로 두고 Notion의 `수업 자료`에 PDF를 넣는다. Alt에서도 슬라이드를 따로 보려면 PDF로 내보낸 뒤 별도의 `슬라이드` 노트를 만든다. 이후 Alt 버전에서는 동작이 달라질 수 있다.
- Alt 원문과 전체 녹취는 접힌 `원본 자료`에서 확인한다. Alt 노트가 삭제되거나 연동 범위를 벗어나면 원문은 제거되고 삭제 revision 표지만 남으며, 다음 정리에서 해당 원본만으로 만든 AI 내용도 함께 정리된다. 직접 필기는 영향을 받지 않는다.
- 예전 페이지에 `AI 수업 노트`나 `AI 회차 교재`가 남아 있어도 바로 손으로 옮길 필요는 없다. 다음 실제 정리 때 현재 원본으로 `AI 학습 교재` 자식 페이지를 만들고, 자동화 소유가 확인된 예전 AI 블록만 검증 후 정리한다. 소유가 불확실한 블록과 직접 필기는 그대로 둔다.
- 동기화가 늦으면 15분 안에 한 번 더 확인하고, 계속 비어 있으면 Worker의 `/health`에서 오류 여부를 본다.

교재는 모든 핵심 근거의 포함 여부, 설명 깊이, 문제와 해설의 일치, 가독성과 직접 필기 보존을 검수해 90점 이상일 때만 교체한다. 중요한 근거가 빠졌거나 PDF를 끝까지 읽지 못했거나 정답이 불완전하면 직전의 정상 교재를 유지하고 다시 시도한다. 일정 상태나 완료 여부는 따로 관리할 필요가 없다.
